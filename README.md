# GCN-Based DCR Prediction and FRP Recommendation

This project focuses on predicting Demand Capacity Ratio (DCR) values of reinforced concrete columns using Graph Convolutional Networks (GCNs) under different FRP retrofitting configurations.

## Project Overview

The work involves representing structural column systems as graph-based data and leveraging Graph Convolutional Networks (GCNs) to model relationships between structural elements for DCR prediction.

Additionally, a database-driven recommendation system is implemented to identify optimal FRP wrapping configurations capable of reducing DCR values toward safer ranges.

## Features

- GCN-based DCR prediction
- Structural graph visualization
- Train vs Validation loss analysis
- Actual vs Predicted DCR comparison
- Feature importance analysis
- Database-driven FRP recommendation system
- Optimization-based FRP selection
